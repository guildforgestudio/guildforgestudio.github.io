# GuildForge Studio — downloads

Public downloads and the download page for **GuildForge Studio**, a Windows app
for building and running Discord servers.

**[Download the latest release](https://github.com/psofos213/guildforge-releases/releases/latest)**
· **[Download page](https://psofos213.github.io/guildforge-releases/)**

This repository holds only the installer and the page that links to it. The
application source is not here.

## Installing

Windows 10 or 11, 64-bit. The build is not code-signed, so Windows shows a blue
"Windows protected your PC" screen — choose **More info**, then **Run anyway**.
That warning is about the missing signature, not about anything found in the
file. Each release lists a SHA-256 you can check the download against.

You need a Discord account and a server you manage. There is no bot token to
paste and nothing to host.
