If your antivirus deletes the file

Some setups quarantine it the moment it lands. It is a false positive, and it happens because the file is new, unsigned, and has no download history yet — not because anything was found in it. To get it back:

Windows Security → Virus & threat protection → Protection history → find the blocked item → Actions → Allow on device, then download again.

You can check the file yourself before trusting any of that. Every download should have this exact fingerprint:

3A355A4A6EFF8841BA63D67744A20A057EEC697C5989783575A6AF098E531F96

See it on VirusTotal — scanned by around seventy engines. If your copy's fingerprint does not match the one above, do not run it, and tell me.

Windows is going to warn you. Here's why

The build isn't code-signed yet, so SmartScreen throws up a blue “Windows protected your PC” screen. Click More info, then Run anyway. That warning is about a missing signature — not about anything it found in the file.

After that it's just the app: sign in with Discord, invite the bot to a server you manage, and start building. It talks to Discord and to the GuildForge service, and nothing else.
